# Native-HD opening

This standalone code creates a 30-second, three-camera animated opening at **1920×1080, 24 fps, 720 frames**. Its geometry, typography, materials, lighting and keyframes are generated by Blender. No external models, downloads, Python packages or API keys are needed. The faceless athletes are original stylized figures, not player likenesses. Eevee engine selection supports the identifiers used by Blender 4.5 and Blender 5.2.

Open Terminal in this folder on the Mac, with the permitted Blender installation available:

```bash
bash run.sh preview
bash run.sh build
bash run.sh render
```

For an editable scene first, run `bash run.sh build`, then open `opening-hd.blend` in Blender. Press **Space** over the timeline to play the animation; press **Numpad 0** to look through the active camera. Viewport playback quality and speed differ from the final render. The file already contains all three cameras and their timed cuts.

```bash
bash run.sh build
open opening-hd.blend
```

On a MacBook without a number pad, choose **View → Cameras → Active Camera** in the 3D viewport. If `.blend` files are not associated with Blender, use **File → Open** inside Blender instead of the `open` command.

`preview` renders nine native-1080p diagnostic images at the beginning/middle/end of each shot. `build` writes the editable `opening-hd.blend` and `motion-report.json` without rendering. `render` creates `frames/frame_0001.png` through `frame_0720.png`. Existing frames are never silently overwritten.

The nine Windows test frames average about 2.3 MB each. Allow approximately **1.5–2 GB for all 720 PNGs**, plus space for the `.blend`, previews and final video; this is an estimate from the samples, not a measured full-render size. The code packet is much smaller and needs no scene assets. The 720-frame HD render is prepared for the Mac and has not been completed on Windows.

After an interrupted render:

```bash
bash run.sh resume
```

Resume requires unchanged scripts and manifest, and checks every saved PNG's dimensions, CRCs and decoded pixel length against `render-state.json`. A frame saved immediately before interruption but absent from the ledger causes a clear stop for inspection. Keep all files and logs rather than deleting them; use a fresh copy of the code packet when changing geometry or settings.

If Blender is elsewhere, set `BLENDER_BIN` to its approved executable path. The default is `/Applications/Blender.app/Contents/MacOS/Blender`. Each run writes a uniquely named log, which can be sent back with diagnostic frames for debugging.

The motion report checks cuts at frames **357 and 572**, parented moving feed labels, planted shoe height, articulated shoulder/elbow motion, camera movement and rotating/moving footballs. A successful build or unit test does not substitute for visual inspection.

The frames are silent: narration, subtitles and final video assembly are performed on Windows. Keep the lower 110 pixels available for caption finishing. The existing `../opening/` packet is retained unchanged. Native macOS execution must still be checked on the actual machine; Windows Blender verification is recorded in the project status.
